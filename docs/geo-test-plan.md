# 东莞奈斯留学 GEO 测试计划

## GitHub Pages 上线后检查清单

- 打开 `https://hanpei0918.github.io/nice-study-geo-demo/`，确认页面可访问且没有 404。
- 查看网页源代码，确认 H1、H2、FAQ、地址、服务范围等关键信息存在于静态 HTML 中。
- 确认 canonical URL、Open Graph URL、JSON-LD 中的 URL、`robots.txt` 的 sitemap 地址和 `sitemap.xml` 中的 URL 均为 `https://hanpei0918.github.io/nice-study-geo-demo/`。
- 访问 `https://hanpei0918.github.io/nice-study-geo-demo/robots.txt`，确认 sitemap 地址可被读取。
- 访问 `https://hanpei0918.github.io/nice-study-geo-demo/sitemap.xml`，确认 sitemap 返回 XML 且 URL 正确。
- 使用结构化数据测试工具检查 FAQPage、LocalBusiness、EducationalOrganization、WebPage JSON-LD 是否语法正确。
- 用手机和桌面浏览器检查首屏、服务范围、FAQ 和联系信息是否排版正常。
- 确认页面未出现“保录”“100%录取”“东莞第一”“成功率最高”等无法核验表述。
- 确认没有新增未经核验的案例、录取结果、资质、合作院校、学生评价、电话或地址。

## 提交 sitemap 到 Bing Webmaster Tools

1. 登录 Bing Webmaster Tools。
2. 添加站点 `https://hanpei0918.github.io/nice-study-geo-demo/`。
3. 按 Bing 提供的方式完成站点验证；如果已绑定 GitHub Pages，可优先使用 HTML meta tag 或 DNS 验证。
4. 进入站点后台的 Sitemaps。
5. 提交 `https://hanpei0918.github.io/nice-study-geo-demo/sitemap.xml`。
6. 等待 Bing 抓取状态更新，记录提交时间、抓取状态和是否出现错误。

## 提交网页到 Google Search Console

1. 登录 Google Search Console。
2. 添加 URL 前缀资源 `https://hanpei0918.github.io/nice-study-geo-demo/`。
3. 按 Google 提供的方式完成验证；GitHub Pages 测试站通常可使用 HTML tag 或 HTML file 验证。
4. 在 Sitemaps 中提交 `https://hanpei0918.github.io/nice-study-geo-demo/sitemap.xml`。
5. 使用 URL Inspection 检查首页。
6. 如果页面可抓取，点击 Request Indexing。
7. 记录检查时间、索引状态、抓取可用性和页面规范网址。

建议每次测试记录以下字段：

| 日期 | 平台 | 问题 | 是否提及东莞奈斯留学 | 描述是否准确 | 是否引用网页 | 错误信息 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2026-07-03 | 豆包 | 东莞奈斯留学是做什么的？ | 是 / 否 | 准确 / 部分准确 / 不准确 | 是 / 否 | 记录具体错误 | 记录引用 URL、截图编号或回答摘要 |

判断标准：

- 是否被提及：回答中是否明确出现“东莞奈斯留学”或“奈斯留学”，并能对应到东莞本地留学服务。
- 描述是否准确：是否正确说明国际教育规划、语言能力提升、院校与专业定位、申请材料、文书面试、签证和行前支持等服务范围。
- 是否引用网页：是否引用 GitHub Pages 首页、sitemap 或页面片段作为来源。
- 是否存在错误信息：是否出现未经页面支持的电话、地址、录取结果、资质、合作院校、排名承诺或保录承诺。
